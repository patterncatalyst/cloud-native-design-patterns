# Example 03: Composition, C++

Three services, built from this directory (the compose build context):

| Service | Port | Stack |
|---------|------|-------|
| `gateway` | 8080 | Drogon, cppgraphqlgen (GraphQL), grpc++ client |
| `order-api` | 8081 | Drogon (REST), libpq |
| `inventory-service` | 50051 | grpc++ sync server |

Toolchain: C++23 (`CMAKE_CXX_STANDARD 23`, no extensions), GCC 15 (`gcc-toolset-15`), CMake 4.4.4,
Ninja 1.13.2, Conan 2.33.0, on `ubi10/ubi:10.2`; runtime `ubi10/ubi-minimal:10.2` as UID 1001 (group 0)
with libstdc++ and libgcc linked statically.

## gateway

- **GraphQL**: cppgraphqlgen 4.5.9. `src/graphql/schema.graphql` is the schema (`orders(limit: Int = 50)`,
  `order(id: String!)`, `Order.stock`); the C++ next to it (`GatewaySchema.*`, `OrderObject.*`,
  `QueryObject.*`) is **generated by schemagen and committed**. Resolvers: `src/graphql_api.hpp`.
- **Stock only when selected, batched once**: `Order.stock` is its own resolver, so a query that does not
  select it never calls inventory. Every request carries a `StockState` (cppgraphqlgen `RequestState`,
  `src/stock_loader.hpp`): the query resolvers register the SKUs they return, and the first `stock` resolver
  triggers one `GetStockBatch` call for all of them
  (log line `DataLoader batched N skus in one gRPC call`). If the lookup fails, `stock` is `null`.
- **Threads**: resolvers block on order-api and inventory, so each GraphQL request runs on a worker thread
  and not on a Drogon event-loop thread.
- **Tests**: `tests/graphql_test.cpp` (ctest inside the image build) covers field selection, the single
  batch call, no call without `stock`, and the failure path, against fakes.

cppgraphqlgen is not on ConanCenter, so its recipe lives in `gateway/conan-recipes/cppgraphqlgen/` and the
Containerfile runs `conan export` on it before `conan install`.

### Regenerating the GraphQL code

After changing `schema.graphql` (from this `cpp/` directory):

```bash
docker build --target schemagen -t cndp-03-schemagen -f gateway/Containerfile .
(cd gateway/src/graphql && \
 docker run --rm -v "$PWD:/work:Z" --user "$(id -u):$(id -g)" cndp-03-schemagen \
   --schema=schema.graphql --prefix=Gateway --namespace=gateway)
```
